---
title: Run types
description: Reference for the run types that identify the kind of operation each span represents in a LangSmith trace.
mode: wide
---

Each span in a LangSmith trace has a `run_type` that identifies the kind of operation it represents. LangSmith uses the run type to apply appropriate rendering in the trace UI and to enable type-specific features.

| Run type | Description |
|----------|-------------|
| `chain` | A sequence or composition of steps. Includes `RunnableSequence` and `RunnableParallel` variants. |
| `llm` | A call to a language model. Displays provider-specific icons for OpenAI, Anthropic, and DeepSeek. |
| `prompt` | A prompt template that formats inputs before passing them to a model. |
| `tool` | A function or external action invoked by the model. |
| `retriever` | A lookup that fetches relevant documents or context. |
| `parser` | An output parser that transforms raw model output into a structured format. |

Set `run_type` when instrumenting with `@traceable` or `RunTree`:

```python
from langsmith import traceable

@traceable(run_type="tool")
def my_tool(query: str) -> str:
    ...
```

For run types with dedicated UI rendering, see:

- [Log LLM calls](/langsmith/log-llm-trace)
- [Log retriever traces](/langsmith/log-retriever-trace)
